# Algoritmos e Estruturas de Dados

Aqui você implementa "na mão" coisas que o Python já faz pronto, para entender como funcionam por dentro.

## O que estudar
- Algoritmos de ordenação: bubble sort, selection sort, insertion sort
- Busca linear x busca binária
- Pilha (LIFO) com lista: `append()` e `pop()`
- Fila (FIFO) com `collections.deque`: `append()` e `popleft()`
- Noções de complexidade (Big O): por que `i * i <= n` deixa o teste de número primo mais rápido?

📖 Referência: https://docs.python.org/pt-br/3/tutorial/datastructures.html
