# Tuplas e Sets

Duas estruturas que faltavam depois de **Listas** e **Dicionários**.

## O que estudar
- Tuplas: sequências imutáveis, empacotamento e desempacotamento (`x, y = ponto`)
- Quando usar tupla em vez de lista
- Sets (conjuntos): elementos únicos, sem ordem
- Operações de conjunto: união `|`, interseção `&`, diferença `-`
- Usar `set` para remover duplicados e fazer buscas rápidas com `in`

📖 Documentação: https://docs.python.org/pt-br/3/tutorial/datastructures.html
