# Tratamento de Erros

Até aqui, se o usuário digitar uma letra onde se espera um número, o programa quebra.
Nesta etapa você aprende a prever e tratar esses erros.

## O que estudar
- Diferença entre erro de sintaxe e exceção
- `try`, `except`, `else` e `finally`
- Exceções comuns: `ValueError`, `ZeroDivisionError`, `KeyError`, `IndexError`, `FileNotFoundError`
- Capturar a mensagem do erro: `except ValueError as erro:`
- Lançar seus próprios erros com `raise`

📖 Documentação: https://docs.python.org/pt-br/3/tutorial/errors.html
