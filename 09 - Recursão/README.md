# Recursão

Uma função recursiva é uma função que **chama a si mesma** para resolver uma versão menor do mesmo problema.

## O que estudar
- Caso base (quando a função para) e caso recursivo (quando ela chama a si mesma)
- Como a pilha de chamadas funciona (e o erro `RecursionError`)
- Comparar a versão recursiva com a versão com laço (você já fez Fibonacci e potência com laços!)
- Memoização com `functools.lru_cache` para deixar funções recursivas rápidas
- Problemas clássicos: fatorial, Fibonacci, soma de dígitos, palíndromos, busca binária

📖 Documentação: https://docs.python.org/pt-br/3/library/functools.html#functools.lru_cache
