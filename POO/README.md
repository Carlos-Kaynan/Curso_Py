# POO — Programação Orientada a Objetos

Na POO você junta **dados** (atributos) e **comportamentos** (métodos) em um mesmo lugar: a classe.

## O que estudar
- Classe x objeto, `__init__` e `self`
- Atributos e métodos
- `__str__` para mostrar o objeto com `print()`
- Encapsulamento (atributos "privados" com `_` e `@property`)
- Herança (`class Gerente(Funcionario):`) e `super()`
- Polimorfismo: classes diferentes respondendo ao mesmo método
- `@dataclass` para classes que guardam dados

Dica: vários exercícios desta pasta são versões orientadas a objetos de exercícios que você já fez.
