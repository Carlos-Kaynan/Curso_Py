# Módulos e Bibliotecas

O Python já vem com uma biblioteca padrão enorme. Saber usá-la evita reinventar a roda.

## O que estudar
- `import`, `from ... import ...` e apelidos (`import datetime as dt`)
- `math`: `pi`, `sqrt`, `ceil`, `floor`
- `random`: `randint`, `choice`, `shuffle`
- `datetime`: datas, diferenças entre datas, `strptime` e `strftime`
- `collections`: `Counter`, `defaultdict`, `deque`
- Criar seus próprios módulos e importar funções de outro arquivo
- Instalar bibliotecas externas com `pip` dentro de um ambiente virtual (`python -m venv .venv`)

📖 Documentação: https://docs.python.org/pt-br/3/tutorial/modules.html
