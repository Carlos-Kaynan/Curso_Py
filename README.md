# Curso_Py
Curso python do Básico ao Avançado

Cada pasta é um módulo. Os exercícios seguem sempre o mesmo formato: um enunciado (**Problem Statement**) com a entrada (**Input**), a saída esperada (**Output**) e exemplos, seguido da solução.

## 🗺️ Trilha de estudos

### Básico ✅
- [01 - Conceitos Básicos](01%20-%20Conceitos%20Básicos): variáveis, operadores, `input()` e `print()`
- [02 - Estruturas Condicionais](02%20-%20Estruturas%20Condicionais): `if`, `elif` e `else`
- [03 - Estruturas de Repetição](03%20-%20Estruturas%20de%20Repetição): `for`, `while` e `break`
- [04 - Listas](04%20-%20Listas)
- [05 - Dicionarios](05%20-%20Dicionarios)
- [06 - Funções](06%20-%20Funções)

### Intermediário 🚧
- [07 - Funções Avançadas](07%20-%20Funções%20Avançadas): `return`, parâmetros padrão, `*args`, `lambda`
- [08 - Tuplas e Sets](08%20-%20Tuplas%20e%20Sets)
- [09 - Recursão](09%20-%20Recursão)
- [10 - Tratamento de Erros](10%20-%20Tratamento%20de%20Erros): `try` / `except` / `raise`
- [11 - Módulos e Bibliotecas](11%20-%20Módulos%20e%20Bibliotecas): `math`, `datetime`, `collections`
- [12 - Arquivos](12%20-%20Arquivos): TXT, CSV e JSON

### Avançado 🚧
- [13 - POO](13%20-%20POO): classes, herança, polimorfismo e `dataclass`
- [14 - Testes](14%20-%20Testes): `assert` e `pytest`
- [15 - Algoritmos](15%20-%20Algoritmos): ordenação, busca binária, pilha e fila
- [16 - Automação](16%20-%20Automação): arquivos, planilhas, APIs e web scraping

> Nos módulos 🚧 os exercícios têm só o enunciado: a solução fica por sua conta!

## ▶️ Como executar um exercício
```bash
python "01 - Conceitos Básicos/qual_lucro.py"
```
Digite as entradas na ordem descrita no enunciado.
