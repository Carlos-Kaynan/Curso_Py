# Curso_Py
Curso python do Básico ao Avançado

Cada pasta é um módulo. Os exercícios seguem sempre o mesmo formato: um enunciado (**Problem Statement**) com a entrada (**Input**), a saída esperada (**Output**) e exemplos, seguido da solução.

## 🗺️ Trilha de estudos

### Básico ✅
1. [Conceitos Básicos](Conceitos%20Básicos): variáveis, operadores, `input()` e `print()`
2. [Estruturas Condicionais](Estruturas%20Condicionais): `if`, `elif` e `else`
3. [Estruturas de Repetição](Estruturas%20de%20Repetição): `for`, `while` e `break`
4. [Listas](Listas)
5. [Dicionarios](Dicionarios)
6. [Funções](Funções)

### Intermediário 🚧
7. [Funções Avançadas](Funções%20Avançadas): `return`, parâmetros padrão, `*args`, `lambda`
8. [Tuplas e Sets](Tuplas%20e%20Sets)
9. [Recursão](Recursão)
10. [Tratamento de Erros](Tratamento%20de%20Erros): `try` / `except` / `raise`
11. [Módulos e Bibliotecas](Módulos%20e%20Bibliotecas): `math`, `datetime`, `collections`
12. [Arquivos](Arquivos): TXT, CSV e JSON

### Avançado 🚧
13. [POO](POO): classes, herança, polimorfismo e `dataclass`
14. [Testes](Testes): `assert` e `pytest`
15. [Algoritmos](Algoritmos): ordenação, busca binária, pilha e fila
16. [Automação](Automação): arquivos, planilhas, APIs e web scraping

> Nos módulos 🚧 os exercícios têm só o enunciado: a solução fica por sua conta!

## ▶️ Como executar um exercício
```bash
python "Conceitos Básicos/qual_lucro.py"
```
Digite as entradas na ordem descrita no enunciado.
